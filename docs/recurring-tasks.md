# Recurring tasks

## Goal

- Read this document and apply the steps to the project.
- Present the plan with coded, prioritized actions, to assess them and carry out the ones that add value.

## Code review

- Apply SOLID principles to the code.
- Use official documentation for the programming language and libraries.
- Use functional programming techniques where appropriate.
    - Immutability by default
    - Algebraic data types (ADTs)
    - Exhaustive pattern matching
    - Option and Result instead of null and exceptions
    - Closures and higher-order functions
    - Lazy iterators
    - Almost everything is an expression
    - Traits as type classes
    - Type inference
- Use stable and well-maintained libraries.
- Avoid using deprecated libraries or features.
- Avoid code duplication.

## Continuous integration

- Review GitHub Actions workflows for efficiency and security.
- Use official documentation for GitHub Actions and CI/CD best practices.
